# credit_card_fraud_detection_model
· Developed an end-to-end Credit Card Fraud Detection pipeline involving data preprocessing, feature scaling, exploratory
data analysis (EDA), and handling highly imbalanced transaction datasets containing fraudulent transactions below 1% of
total data.
· Implemented and compared Logistic Regression, Random Forest, Support Vector Machine (SVM), and Artificial Neural
Network (ANN) models, achieving up to 91% fraud recall on unseen test data.
· Applied imbalance handling techniques such as undersampling and class-weight optimization, and analyzed precision–recall
tradeoffs using confusion matrices and comparative performance visualizations to evaluate fraud detection effectiveness.
